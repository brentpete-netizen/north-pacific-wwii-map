# North Pacific, 1942–1943

An interactive map of the Aleutian campaign and the Battle of Midway, from the Dutch Harbor raid in June 1942 through the evacuation of Kiska in 1943.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints, usually http://localhost:5173.
